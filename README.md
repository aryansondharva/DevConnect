# DevConnect

**Connecting developers through open collaboration.**

A community-maintained directory for developers, students, and technology enthusiasts to connect, discover projects, and collaborate.

[Explore members](developers/README.md) · [Join DevConnect](CONTRIBUTING.md) · [Community standards](CODE_OF_CONDUCT.md)


## About

DevConnect helps people discover other developers through a simple, public directory. Members can share their GitHub profile, an optional X account, and the technologies they work with. Every update is reviewed through a GitHub pull request.

## How to join

1. Fork this repository.
2. Open [`developers/README.md`](developers/README.md) in your fork.
3. Add one row to the **Community members** table with your details.
4. Commit your change and open a pull request against this repository's `main` branch.
5. Once approved and merged, your profile appears in the directory.

For examples and submission rules, read [CONTRIBUTING.md](CONTRIBUTING.md). You can contribute entirely from GitHub's browser editor; no Git installation is required.

## Community directory

Browse the [member directory](developers/README.md) to find people working on web development, data structures, open source, and other fields.

## Sharing and community activity

You may share your merged contribution on X with **#DevConnect**. Sharing, following, reposting, and starring are optional and do not affect whether a valid contribution is accepted.

GitHub displays public stars, forks, and pull requests. Repository owners can access aggregate clone metrics, but **cannot identify individual people who cloned the repository**. X shares cannot be fully tracked automatically; public hashtag posts and voluntarily supplied links offer partial visibility only.

## Community standards

Be respectful, share only public information you have the right to share, and do not alter another member's details without permission. See the [Code of Conduct](CODE_OF_CONDUCT.md).
