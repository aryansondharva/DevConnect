# Contributing to DevConnect

Thank you for your interest in joining DevConnect. This guide explains how to add yourself to the community directory.

## Add your profile

The directory uses **one file** for all members: [`developers/README.md`](developers/README.md). You do not need to create an individual profile file.

1. Open the [DevConnect repository](https://github.com/aryansondharva/DevConnect) and select **Fork**.
2. Open `developers/README.md` in your fork and select **Edit** (pencil icon).
3. Add one new row to the end of the **Community members** table. Do not overwrite or edit an existing member's entry.
4. Replace the placeholders in the example below with your own information.
5. Select **Commit changes** and use a message such as `docs: add @yourusername to community directory`.
6. Select **Contribute → Open pull request** to propose your change to the upstream `main` branch.
7. A maintainer will review your pull request and may request formatting corrections before merging.

You can complete this process in a browser without installing Git.

## Example entry

Add a single row in this format:

```markdown
| Your Name | [@yourusername](https://github.com/yourusername) | [@yourhandle](https://x.com/yourhandle) | React, JavaScript, Python |
```

The X account is optional. If you do not use X, write `—` in that column. List a few relevant skills or interests rather than a long biography.

## Submission requirements

- Submit only your own public information, or information shared with explicit permission.
- Use accurate names and working public links. No impersonation or deceptive entries.
- Do not post private contact details, secrets, access tokens, or sensitive personal information.
- Do not edit or remove another person's row without authorization.
- Keep each pull request focused on one entry or one clearly explained documentation improvement.
- No spam, advertising, harassment, or abusive content.
- Follow the [Code of Conduct](CODE_OF_CONDUCT.md).

Maintainers may request changes or decline contributions that do not meet these requirements.

## Optional X participation

After your contribution is merged, you can share it using **#DevConnect** and a link to your pull request. Following anyone, reposting, and starring are never required for approval.

## Other contributions

Suggestions that improve accessibility, documentation, or directory usability are welcome. For substantial changes, open an issue to discuss your proposal first.

## Need help?

If you have a question about your contribution, open an issue in the repository. Do not share sensitive information in public issues.
